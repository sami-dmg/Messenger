# Real-Time Chat App 💬🔥

A secure, instantaneous web messaging application built for real-time communication and robust user authentication.

## ✨ Features
- **Instant Messaging:** Low-latency real-time message broadcasting.
- **Secure Authentication:** Quick login integration using Google Auth.
- **Cloud Database:** Persistent message synchronization via Firebase Firestore.

## 🛠️ Tech Stack
- **Frontend:** JavaScript (ES6+), HTML5, CSS3
- **Backend & Auth:** Firebase Firestore & Google Authentication
